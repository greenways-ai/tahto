# Introduction

Tahto is the Greenways semantic and synchronization fabric. Applications use it for semantic collections, stable IDs, typed links, exact roots, divergence, and closure synchronization.

## Before you begin

Tahto is intentionally application-neutral. Greenways OS owns installation, device identity, pairing, key custody, consent, grants, credentials, providers, and backup policy. Applications and installed specification packages own domain rules and merge policy.

Start with [the authority boundary](../../concepts/authority-boundary/) before integrating an application.

## Current maturity

The semantic model and pure read, prepare, and submit kernels exist. Production integration still requires installed validator routing, authenticated semantic routes, provider composition, and the complete signed two-device recovery proof. The [status page](../../project/status/) separates implemented kernel laws from installed service availability.
