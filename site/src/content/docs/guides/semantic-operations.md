# Semantic operations

Use the three-stage kernel deliberately:

1. Read an exact bounded value and its evidence.
2. Prepare a candidate operation against the expected semantic root.
3. Submit the exact prepared result with authenticated request evidence.

The validator comes from an exact installed specification package. A schema reference is data identifying that package and exported entry; it is never authority to fetch or execute remote code.
