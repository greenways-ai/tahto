# Contributing

Before changing Tahto, read the repository contributor contract and the protocol nearest your change. Keep domain policy in applications, physical mechanics in generic providers, and semantic orchestration in HAL.

Changes should include focused conformance evidence and explain authority, storage, migration, compatibility, and security consequences.

[Read the contributor contract ↗](https://github.com/greenways-ai/tahto/blob/main/AGENTS.md)
