# Status and roadmap

## Implemented

Semantic value profiles, object admission, stable indexes and roots, history integration, pure read/prepare/submit kernels, pairing, signed-request law, and generic value-store adaptation.

## Still in integration

Filesystem provider extraction, distribution composition, installed specification validation, semantic routes, authentication, response-source integration, compiler-free worker boot, and the full signed two-device restart/recovery fixture.

Track the ordered work in [Tahto issue 29 ↗](https://github.com/greenways-ai/tahto/issues/29).
