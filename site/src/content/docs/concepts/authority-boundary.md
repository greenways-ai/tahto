# Authority boundary

## Tahto owns

Semantic collections, stable logical identities, typed content-addressed links, exact roots, graph closure, divergent heads, synchronization planning, and semantic transaction validation.

## Other layers own

- **Greenways OS:** identity, keys, credentials, consent, grants, providers, installation, and backup policy.
- **Ignatius and generic storage:** immutable block custody, scoped refs, physical persistence, and bounded transport.
- **Applications and installed specs:** domain fields, invariants, transforms, migrations, and merge policy.

Portable Hara values cannot select a native ABI, provider package, database path, storage root, credential, command, or remote executable catalogue.
